# AWS Learning Hub — CLF-C02

Plataforma estática de apoio aos estudos para AWS Certified Cloud Practitioner.

## Funcionalidades
- Dashboard com indicadores de desempenho.
- Trilha dos quatro domínios do exame.
- Banco de questões com correção comentada.
- Histórico persistente de tentativas via LocalStorage.
- Caderno automático de questões incorretas.
- Flashcards e método de estudo.

## Tecnologias
HTML5, CSS3, JavaScript e LocalStorage.

## Executar localmente
Abra `index.html` em um navegador. Não requer instalação nem servidor.

## Persistência e privacidade
As respostas são armazenadas no LocalStorage do navegador e neste dispositivo/perfil de navegador. Os dados não são enviados ao GitHub nem sincronizados entre dispositivos. Limpar os dados do navegador pode apagar o histórico.

## Publicação
Configure GitHub Pages para publicar a branch `master` a partir da pasta `/ (root)`.

## Observação
As questões incluídas são demonstrativas e autorais; não são questões oficiais do exame AWS. Consulte o guia oficial da certificação para os objetivos atualizados.
